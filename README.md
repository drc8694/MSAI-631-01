# Traditional Rule-Based Chatbot

## Overview
This project implements a traditional rule-based chatbot using Python. The chatbot uses regex pattern matching and predefined responses instead of large language models or machine learning.

The chatbot was developed as part of the Artificial Intelligence for Human-Computer Interaction course.

## Features
- Greeting recognition
- Farewell handling
- Name extraction
- Help requests
- Conversation history
- Malformed input handling
- Unit testing

## Technologies Used
- Python
- Regex
- unittest
- PyCharm

## Files
- simple_chatbot.py → Main chatbot implementation
- test_chatbot.py → Unit tests for chatbot functionality

## How to Run

Run chatbot:
python chatbot.py

Run tests:
python test_chatbot.py
