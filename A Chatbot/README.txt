# Simple Traditional Chatbot Project

## Overview
This project is a traditional rule-based chatbot developed using Python. 
The chatbot responds to greetings, help requests, time-related questions, and malformed inputs using regex-based intent recognition and predefined responses.

## Technologies Used
- Python
- Regex
- Google Colab
- PyCharm
- Anaconda Environment

## Features
- Intent recognition
- Predefined chatbot responses
- Conversation history tracking
- Handling malformed input
- Automated unit testing

## Files Included
- chatbot.py
- test_chatbot.py
- report.docx
